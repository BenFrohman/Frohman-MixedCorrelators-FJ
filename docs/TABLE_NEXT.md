# The next object

Author: Benjamin Stanley Frohman. Copyright (c) 2026. Apache-2.0.

The solution of the Frohman problem is the finite table of genus-zero primary three-point numbers

    <α, β, γ>_{0,3}^{F, ⟨J⟩}
    = ∫_{[M-bar_{0,3}^{F,⟨J⟩}]^{vir}}

on F-spin moduli. That table is the next object. It is not written.

## Selection rule

A triple is allowed only if the decorations multiply to J.
The state space is 2610 = 2605 broad + 5 narrow.

## Rows that exist without the virtual class of F

1. Identity-sector pure tensors (algebra, not F-spin moduli).
   If α = a1⊗a2⊗a3 and likewise for β, γ, all in Jac(W),
   the Jacobian pairing factors:
   product_k coeff_{u^3 v^5}(a_k b_k c_k).
   Forty-two unordered W-triples, values in {1, -6}.
   This is Jac(F), not the mixed virtual class.

2. Narrow Lefschetz line.
   The five states track 1, ω, ω^2, ω^3, ω^4.
   Classical intersection on X: ∫_X ω^4 = 6.
   String / pairing among those five is not a mixed broad-narrow number.

## Rows that do not exist yet

- Mixed broad-narrow triples (one or two insertions from Jac(F)^J, the rest from J^k).
- Mixed-block broad tensors that are not pure tensors.
- Any number produced by filling a slot with 0, 1, or 6 by hand.

Those rows require the Polishchuk-Vaintrob class on M-bar_{0,3}^{F,⟨J⟩},
or a reconstruction theorem proved for this group (not G_max, not one chain).

Guéré gives Hodge integrals on one chain. Krawitz reconstructs G_max.
Neither writes this table.
