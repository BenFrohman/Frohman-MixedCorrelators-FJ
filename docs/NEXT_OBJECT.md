# Next object: the mixed correlator table

Author: Benjamin Stanley Frohman. Copyright (c) 2026. Apache-2.0.

The solution of the Frohman problem is a finite table of

    ⟨α, β, γ⟩_{0,3}^{F, ⟨J⟩}
    = ∫_{[M-bar_{0,3}^{F,⟨J⟩}]^vir}

for every triple of states in the 2610-dimensional space of (F, ⟨J⟩)
allowed by the selection rule. That table is the next object. It is not written.

## Basis

- Broad sector B: Jac(F)^J, dim 2605, Hilbert (1, 426, 1751, 426, 1).
- Narrow sector N_k, k=1..5: one state each, Lefschetz line.

Total 2610.

## Blocks of the table

| Block | Insertions | Status |
|---|---|---|
| NNN | three narrow | axiom / string / volume; ∫_X ω^4 = 6 is one number, not the table |
| BBB, same-block pure tensors | three broad, each a pure tensor of W-states | Jac(F) residue product exists; that is algebra, not the virtual class of F |
| BBB, mixed-block | three broad, states mixing the three W-summands | OPEN |
| BBN, BNN | mixed broad–narrow | OPEN |

Filling any OPEN cell with 0, 1, or 6 is recorded as not proved.

## Selection rule

Decorations multiply to J. Age / degree constraint of FJRW genus zero.
Triples that fail the rule are zero by definition, not by computation.

## What would close the object

Every OPEN cell evaluated from [M-bar_{0,3}^{F,⟨J⟩}]^vir,
or from a reconstruction theorem proved for this group ⟨J⟩ (not quoted from G_max, not quoted from one chain).
WDVV then generates the rest of genus zero.
