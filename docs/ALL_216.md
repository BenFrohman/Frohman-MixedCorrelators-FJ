# All 216 ordered decoration triples

Author: Benjamin Stanley Frohman  
Copyright (c) 2026 Benjamin Stanley Frohman  
License: Apache-2.0

Decorations are elements of the cyclic group `⟨J⟩ ≅ Z/6Z`.
An ordered triple `(k, ℓ, m)` with each index in `{0,1,2,3,4,5}` labels the sectors of the three insertions.

- `0` = identity / broad sector (dimension 2605)
- `1,...,5` = narrow Lefschetz states (dimension 1 each)

Genus-zero three-point selection rule:

    k + ℓ + m ≡ 1 (mod 6).

There are `6³ = 216` ordered triples. Exactly `36` pass. The other `180` make the `(F, ⟨J⟩)`-spin stack empty. Those `180` correlators are `0` because there is no moduli space, not because the virtual class was integrated.

Files:
- `tables/all_216_decoration_triples.csv` — every row
- `tables/allowed_36.csv` — the rooms that exist; correlator values stay OPEN
- `tables/excluded_180.csv` — the off-rule zeros

## Census

| kind | allowed deco | excluded deco |
|---|---:|---:|
| BBB | 0 | 1 |
| BBN / BNB / NBB | 1+1+1 = 3 | 4+4+4 = 12 |
| BNN / NBN / NNB | 4+4+4 = 12 | 21+21+21 = 63 |
| NNN | 21 | 104 |
| **total** | **36** | **180** |

Slot sizes after the group-product test only (homogeneity is a second filter, not applied here):

- allowed BBN-type (3 deco): `3 · 2605² = 20,358,075` OPEN cells
- allowed BNN-type (12 deco): `12 · 2605 = 31,260` OPEN cells
- allowed NNN (21 deco): `21` cells; one pairing on the Lefschetz line is `∫_X ω^4 = 6`, not the table

The identity-sector triple `(0,0,0)` is BBB and **excluded**. Three broad states do not satisfy the selection rule. Mixed-block residue algebra of `Jac(F)` is a different table (the 42 triples of `Jac(W)` tensored). It is not an FJRW 3-point of `(F, ⟨J⟩)`.

## The 180 excluded triples

Every remaining `(k, ℓ, m)` in `{0,...,5}³` with `k+ℓ+m ≢ 1 (mod 6)`. Full list: `tables/all_216_decoration_triples.csv` column `selection=EXCLUDED`, and `tables/excluded_180.csv`.

Including the first row of the cube:

    (0,0,0)  BBB  sum=0  EXCLUDED.

That is the three-broad identity-sector triple. Off-rule vanishing. Real zero. Not an OPEN mixed cell.

## What this does and does not prove

Proved: the group-product filter on decorations. 216 = 36 + 180.

Not proved: the value of any of the 36 allowed virtual-class integrals except the geometric volume pairing on one Lefschetz combination, which is a different table.
