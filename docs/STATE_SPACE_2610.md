## The raw split

    dim H_FJRW(F, ⟨J⟩) = 2610 = 2605 + 5.

- 2605 is the broad / identity sector: dim Jac(F)^{J} .
  Graded Hilbert series in degrees 0, 6, 12, 18, 24:

      (1, 426, 1751, 426, 1)

  Sum: 1+426+1751+426+1 = 2605.

- 5 is the five narrow twisted sectors J^k, k = 1,2,3,4,5.
  Each has dimension 1. They are the Lefschetz line.

- 2610 is also dim H^bullet(V(F)) for a smooth sextic fourfold in P^5:

      dim H^0 + H^2 + H^4 + H^6 + H^8
      = 1 + 1 + 2606 + 1 + 1
      = 2610.

  Inside H^4: b_4 = 2606 = 2605 + 1, the extra 1 being ω^2.
  Full h^{2,2} = 1752 = 1751 + 1, same extra 1.

This match is a dimension count. It is not a mixed correlator.
